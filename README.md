# 坂道經理人 · 花咲坂46

繁體廣東話、可跨年經營嘅偶像團體模擬遊戲。純 HTML / CSS / JavaScript，無需後端、API 金鑰或建置工具。

## 玩法

- 一期 12 人；成團一年半後（累計第 79 週）開放二期 12 人。
- 二期實際加入滿 104 週後可招募三期 12 人，最早累計第 183 週。
- 每週 3 行動點；育成、單曲、Live、冠名及村外綜藝。
- Hana Talk 按角色性格、心情、體力及信任度回應。屬遊戲情境對話，並非真人或生成式 AI。
- 年度結算後繼續經營，保留資金、能力及關係。

## GitHub Pages

`index.html`、`style.css`、`game.js` 及 `.nojekyll` 已放喺倉庫根目錄，保留相對路徑，支援 GitHub Pages 專案子目錄。

開啟倉庫 Settings → Pages，選擇 Deploy from a branch，再選 main 及 /(root)，儲存。等待 GitHub 完成部署後，由 Pages 顯示嘅網址進入遊戲。只上傳 zip 檔唔會部署，須先解壓再上傳檔案。

## 搬移進度

存檔只喺目前網址及瀏覽器嘅 localStorage，並無雲端帳戶同步。不同網址，包括原網站及 GitHub Pages，唔會自動共用存檔。

1. 喺舊網址按「匯出存檔」，保存 JSON。
2. 喺新網址按「匯入存檔」，選擇 JSON。
3. 確認週數同成員數，再確認匯入。

匯入前可先備份新網址上已有嘅進度。新版兼容舊版存檔；已在第 52 週正常結算嘅舊存檔會繼續到第二年，因資金不足休團則保持休團。
